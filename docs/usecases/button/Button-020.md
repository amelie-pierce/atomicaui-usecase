# Button-020: Go to carousel page button

Component family: **Button**

UI type: **Single button**

Source: `src/usecase-gallery/usecases/button/Button-020/usecase.ts`

## What it is

An empty solid Button is one dot of a carousel pager; the current page is the primary one.

## When to choose it

Use it only as a page indicator that also jumps to its page. It has no label, so always set aria-label ("1 / 3") and aria-current on the current dot.

## Where it belongs

The footer of the FD input pane carousel: one dot per page of cards.

## Usage guidance

Set aui paint "solid" and color "primary" for the current page, "surface-alt" for the others, on a Button with no children. Measured with no size class: 16px by 10px, orange rgb(255, 83, 8) when current; the app sizes the dot with its own carousel-dot CSS class, which the kit cannot state, so the scene shows the kit box. A Button with no label and a solid fill is not an icon button, so it stays a Single button.
