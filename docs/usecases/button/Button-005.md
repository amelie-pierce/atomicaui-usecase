# Button-005: Try again button

Component family: **Button**

UI type: **Single button**

Source: `src/usecase-gallery/usecases/button/Button-005/usecase.ts`

## What it is

The default gray Button retries a failed action from an error message: Try again under the Results error.

## When to choose it

Use it for a plain recovery action that needs no emphasis; the error View around it carries the colour.

## Where it belongs

The Results error strip, under the message (the HCS Output error state). Real site source: HCS F01Results.tsx; no other app has a Retry Button in its source (checked in ACE, ADM, PFD, PBS, HS, FD, AGPD, RWS and ADC).

## Usage guidance

The example sets only aui scale "sm"; color "surface-alt" and paint "solid" are the defaults. In context the scene is the HCS Output error state: a solid error View with the message, then the button; the View sets no flex props, so the button sits under the message. One group, HCS only.
