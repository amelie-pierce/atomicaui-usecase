# Button-041: Call dealer button

Component family: **Button**

UI type: **Icon button**

Source: `src/usecase-gallery/usecases/button/Button-041/usecase.ts`

## What it is

A round filled accent IconButton calls the dealer.

## When to choose it

Use it for the one prominent icon-only action next to a line of text, here a link that starts a call. The quiet icon buttons are the ghost and tonal ones.

## Where it belongs

The end of the dealer contact line under the AGPD quote form (Need help? and the phone number).

## Usage guidance

Set aui color "primary", paint "solid" and shape "pill" on an IconButton with render set to an anchor (href "tel:"), so the link is the control. Measured: 28px square, 999px radius, white glyph on orange rgb(255, 83, 8). The other icon buttons are transparent, outlined or tonal (Button-028 to Button-040), so a solid fill is its own variant.
