# Button-042: Recalculate button

Component family: **Button**

UI type: **Icon button**

Source: `src/usecase-gallery/usecases/button/Button-042/usecase.ts`

## What it is

A small amber solid IconButton re-runs the calculation when the inputs have changed.

## When to choose it

Use it for an icon-only action that needs attention, here recalculating stale results. Pair it with a title or tooltip that names the action.

## Where it belongs

The header of the ADC results, before the N, V and N + V values.

## Usage guidance

Set aui color "warning", paint "solid", shape "soft", profile "square" and scale "xs" on an IconButton (aria-label and title "Recalculate"). Measured: 26px square, 14px medium glyph, white on amber rgb(217, 119, 6), 4px radius; the other icon buttons are 20px, 24px or 28px and none is solid amber, so it is its own variant.
