# Button-019: Toggle prototype controls button

Component family: **Button**

UI type: **Single button**

Source: `src/usecase-gallery/usecases/button/Button-019/usecase.ts`

## What it is

A surface Button lifted with a shadow floats over the page and toggles a panel of controls.

## When to choose it

Use it for a floating toggle that must stand out from the content behind it. A flat tonal button is Button-009.

## Where it belongs

The corner of the HCS prototype experience, below the prototype controls stack (a prototype-only toggle, not part of the product).

## Usage guidance

Set aui scale "sm", color "surface" and elevation 3 (aria-expanded for the toggle). Measured: 28px high, 4px 8px padding, 16px regular text, white fill with no border and a 0 3px 8px shadow of 15% black; Button-009 has the same size with a 1px border and no shadow, so the shadow is the difference.
