# Chip-003: Tonal status with icon

Component family: **Chip**

UI type: **Status chip**

Source: `src/usecase-gallery/usecases/chip/Chip-003/usecase.ts`

## What it is

A tonal chip with a leading icon that states a result: success and a check for Passed, error and a cross for Failed.

## When to choose it

Use it for a pass or fail state in a table cell. Use a Label chip to name a kind of item (Chip-001).

## Where it belongs

The Status column of the HCS results table (src/components/F01Results.tsx). FD shows the status as a smaller chip with no icon (not catalogued).

## Usage guidance

`Chip` at `scale: "sm"`, `paint: "tonal"`, `color` `success` or `error` by the result, with `Chip.Icon` (circle-check or circle-xmark at `scale: "sm"`) before the text. The scene shows two rows, one per state, and leaves out the other columns.

## Structure (outer to inner)

1. **Chip** — The tonal success chip at scale "sm" shown in the Status column of the HCS results table; a Failed row swaps it for the error colour. Selector: `[class~="aui-chip"]`.
2. **Icon** — The leading "circle-check" icon at scale "sm" that backs the result with a glyph (a cross for Failed). Selector: `[class~="aui-chip-icon"]`.
3. **Label** — The status text "Passed", written directly as the chip's children instead of a Chip.Label. Selector: `[class~="aui-chip"]`. Direct text is highlighted.
