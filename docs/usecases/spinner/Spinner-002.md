# Spinner-002: Large info spinner

Component family: **Spinner**

UI type: **Spinner**

Source: `src/usecase-gallery/usecases/spinner/Spinner-002/usecase.ts`

## What it is

An extra-large info spinner above a message, for a job that holds the user in a dialog.

## When to choose it

Use it when a dialog waits on one job and the message says what to do. Use the small pane spinner (Spinner-001) inside a pane.

## Where it belongs

The generating step of the ADC report flow (src/adc/components/ReportFlow.tsx).

## Usage guidance

`Spinner` with `aui={{ color: "info", scale: "xl" }}`; the message beside it carries the status, so the Spinner is `role="presentation"` and `aria-hidden`. The pair is a centred column View with gap 8.
