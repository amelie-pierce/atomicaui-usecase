# Button-013: Add to Job List button

Component family: **Button**

UI type: **Single button**

Source: `src/usecase-gallery/usecases/button/Button-013/usecase.ts`

## What it is

A solid secondary Button, black with white text, adds the chosen result to the job list.

## When to choose it

Use the labelled Button when one result is chosen elsewhere and must be added to a list; HS disables it until a result is selected or while a job is being edited.

## Where it belongs

The first item of the HS Output toolbar row, before the search field (ResultsTable `actions` slot from OutputPane.tsx). Real site source: HS src/hs/OutputPane.tsx. No other app has this Button.

## Usage guidance

aui color "secondary", paint "solid", scale "sm", text only. In context the button is the first item of a wrapping toolbar row (gap 8). The count, Reset filters, Download CSV and the table are left out. One group, HS only.
