# FileUpload-002: Feedback attachments dropzone

Component family: **FileUpload**

UI type: **FileUpload**

Source: `src/usecase-gallery/usecases/file-upload/FileUpload-002/usecase.ts`

## What it is

A dashed drop area in the Feedback form that attaches several files: the attached files as Chips above the dropzone.

## When to choose it

Use it to take several optional files with a form the user submits once. Use the upload dialog dropzone (FileUpload-001) when the file is the whole action of the dialog.

## Where it belongs

The attachment block of the Feedback form (ADM, PFD, PBS, HS, AGPD, RWS). Real source: the paths in the case.

## Usage guidance

`FileUpload` with `multiple`, `messages={{ idle: { text, action } }}` for the prompt and `onFilesChange`. One group: the attached files as Chips (Chip-005) above the dropzone, with a limits line below. The scene leaves out the file handlers and the size errors.
