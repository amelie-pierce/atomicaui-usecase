# Spinner-001: Small pane spinner

Component family: **Spinner**

UI type: **Spinner**

Source: `src/usecase-gallery/usecases/spinner/Spinner-001/usecase.ts`

## What it is

A small default-colour spinner centred in a pane while its results load.

## When to choose it

Use it for a wait inside one pane. Use the large info spinner (Spinner-002) for a whole-window job with a message.

## Where it belongs

The Output pane while results are checked (HCS F01Results.tsx, PFD OutputPane.tsx).

## Usage guidance

`Spinner` at `scale: "sm"` with an `aria-label` naming what loads. It uses the small scale and default colour while results are recomputed.
