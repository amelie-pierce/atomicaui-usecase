# Button-018: Open products picker button

Component family: **Button**

UI type: **Single button**

Source: `src/usecase-gallery/usecases/button/Button-018/usecase.ts`

## What it is

A full-width small Button with a border stands in for a field until the user activates it.

## When to choose it

Use it for a field-like row that opens a picker on interaction. A row that opens a tutorial is Button-011, at the default size and without a fill.

## Where it belongs

The Products input of the ADC input pane before the picker is active; hover or focus replaces it with the picker.

## Usage guidance

Set aui scale "xs", color "surface", paint "fixed", shape "soft" and sx width "fill", justifyContent "between". Measured: 26px high, 3px 5px padding, 14px medium text, white fill and a 1px rgb(148, 163, 184) border, where Button-011 is 30px high with 16px regular text and no fill, so the size and the fill differ. The scene keeps one row in a 288px column.
