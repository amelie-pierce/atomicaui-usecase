# Chip-004: Compact solid status

Component family: **Chip**

UI type: **Status chip**

Source: `src/usecase-gallery/usecases/chip/Chip-004/usecase.ts`

## What it is

A compact solid chip with an icon for each check category of a result: green and a check when it passes, red and an exclamation when it fails.

## When to choose it

Use it for several short states side by side. Use the tonal chip (Chip-003) in a table cell.

## Where it belongs

Below the model header of each FD result card (src/components/Results.jsx).

## Usage guidance

`Chip` at `scale: "xs"`, `paint: "solid"`, `color` `success` or `danger`, with `Chip.Icon` and `Chip.Label`. The chips sit in a flex row with gap 8. The scene shows one pass and one fail and leaves out the warning messages.
