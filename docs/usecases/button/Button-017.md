# Button-017: Open report button

Component family: **Button**

UI type: **Single button**

Source: `src/usecase-gallery/usecases/button/Button-017/usecase.ts`

## What it is

A small blue solid Button with a file icon tells the user a report is ready and opens it.

## When to choose it

Use it for a status that is also an action: the state is the label and the click opens the result. A neutral action is Button-005; the accent solid is Button-015.

## Where it belongs

The left slot of the ADC status bar, shown once a calculation report exists for the active design (it reads "Report is ready (outdated)" when the inputs changed since).

## Usage guidance

Set aui color "info", paint "solid", scale "xs" and shape "soft", with a Button.Icon "file-lines" and a span label. Measured: 26px high, 4px 6px padding, 14px medium text, white on blue rgb(59, 130, 246), 4px radius, so the colour and the size differ from Button-015 (accent, 28px, 16px). The generating state is the same Button as secondary text, disabled, and is left out with the rest of the bar.
